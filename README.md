# Hotel Oasis — Front-End Demo

A responsive hotel landing page built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Deploy
Upload the three files (`index.html`, `style.css`, `script.js`) to a GitHub repository and import it into Vercel or Netlify. No build command is required; the project is static.

## Important
This is a front-end demo. The date form validates dates and displays a stay summary only. It does not check live room availability, process payments, or create real reservations. Images are loaded from Unsplash and Google Fonts are loaded online.
